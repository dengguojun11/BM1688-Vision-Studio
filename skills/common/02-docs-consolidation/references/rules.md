# Docs Consolidation Rules

- Prefer one primary current-state doc per topic.
- Judge documents against the current codebase and business flow.
- Separate file duplication from content duplication.
- Keep historical value, but move it out of the main reading path when appropriate.
- Do not delete or clean up files without explicit approval when the project requires confirmation.
- If useful content exists in an obsolete document, extract it before deprecating the file.
