# Enterprise Admin Layout Rules

- Keep header concise and authoritative.
- Use KPI strips only when they improve scanning.
- Separate filters from actions clearly.
- Use 2 to 4 strong horizontal zones, not many weak sections.
- Give tables most of the vertical space on record-heavy pages.
- Keep detail drawers structured into titled groups.
- Use side panels to preserve context instead of forcing navigation.
- Treat status badges as part of the language system, not decoration.
- On configuration pages, show dependency context near the setting group.
