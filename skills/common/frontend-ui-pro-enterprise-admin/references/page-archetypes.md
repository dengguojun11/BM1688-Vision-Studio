# Enterprise Admin Page Archetypes

## 1. Management List Workspace

Best for:

- records
- jobs
- assets
- users
- policies

Structure:

- page header
- compact KPI or summary row
- filter toolbar
- main table
- right-side detail drawer or modal detail

## 2. Policy / Config Center

Best for:

- quality rules
- thresholds
- presets
- feature toggles

Structure:

- overview summary
- grouped setting sections
- sticky save region when needed
- clear default vs override presentation

## 3. Workflow Operations Board

Best for:

- multi-stage business chains
- export / validation / publish flows

Structure:

- chain summary row
- stage cards
- current blocker emphasis
- stage-specific actions and artifacts

## 4. Review Queue

Best for:

- approval tasks
- exception handling
- audit review

Structure:

- queue summary
- filter tabs
- compact list/table
- focused detail panel with decision actions
