# Enterprise Admin Table And Form Rules

## Tables

- Put status and primary identifier early.
- Keep row height compact unless rows contain comparison data.
- Use muted metadata lines under the primary identifier when needed.
- Limit actions to the most relevant 1 to 3 visible controls.
- Use overflow menus for lower-priority actions.

## Forms

- Group fields by business meaning, not by backend model order.
- Use section descriptions sparingly and only when helpful.
- Keep validation messages local and precise.
- Make save state visible.
- Surface risky settings with distinct warning styling.

## Density

- Prefer medium density for most enterprise pages.
- Use high density only for expert operational users.
- Use low density only when the page is explanation-heavy.
