# Code Impact Checklist

- Did we identify all changed files?
- Did we classify them by layer?
- Did we find the nearest entry points?
- Did we trace callers and downstream dependencies?
- Did we identify user-facing impact?
- Did we check tests?
- Did we check documents?
- Did we separate confirmed impact from inferred impact?
- Did we call out regression risks?
- Did we propose verification steps?
