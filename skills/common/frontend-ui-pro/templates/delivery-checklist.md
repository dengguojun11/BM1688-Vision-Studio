## Frontend UI Delivery Checklist

- Page archetype chosen intentionally
- Primary action is visually obvious
- Information hierarchy is clear
- Layout pattern matches the business problem
- Typography scale feels deliberate
- Spacing rhythm is consistent
- Status system is clear
- Table or form density is appropriate
- Empty/loading/error states exist
- Responsive behavior checked
- Browser rendering verified
- Final UI does not depend on weak existing project visuals
