# Metrics And Status Layout

- Use 3 to 6 headline metrics at most.
- Separate “headline KPI” from “blocking state”.
- Give urgent warnings their own visual region.
- Keep metric cards compact and aligned.
- Use chips and short descriptors instead of paragraphs.
- Make exception counts easy to spot.
- Do not mix unrelated metrics into the top strip.
- Put raw evidence below summary, not above it.
