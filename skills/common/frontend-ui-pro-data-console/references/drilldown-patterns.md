# Drilldown Patterns

## Detail Drawer

Use when users inspect one item from a large table without leaving context.

## Split Pane

Use when users constantly compare list state and detail state.

## Tabbed Evidence Region

Use when one record has several evidence types:

- logs
- metrics
- artifacts
- screenshots
- raw payloads

## Exception Modal

Use when a rare event needs focused review without cluttering the main page.

## Drilldown Rule

Always keep the operator’s place in the parent view when possible.
