# Data Console Archetypes

## 1. Monitoring Dashboard

Best for:

- global system visibility
- current health
- KPI and alert overview

Structure:

- top summary
- KPI/status strip
- alerts or blockers
- recent activity / queue / throughput sections

## 2. Workflow Hub

Best for:

- multi-stage model or data flow
- lifecycle tracking

Structure:

- current chain summary
- stage progression
- artifacts per stage
- actions per stage
- blocker panel

## 3. Comparison Analysis Page

Best for:

- before/after
- GT vs prediction
- model A vs model B
- expected vs actual

Structure:

- summary metrics
- comparison region
- exceptions table
- detailed evidence area

## 4. Queue And Exception Console

Best for:

- jobs
- failed tasks
- retry flows
- operational exception handling

Structure:

- queue stats
- filter tabs
- priority table
- detail side panel
