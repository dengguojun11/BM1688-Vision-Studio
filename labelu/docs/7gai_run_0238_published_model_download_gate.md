# RUN-0238 模型中心下载开关与 AICM 编号对齐验收

日期：2026-09-20  
层级：本地 L1（生产未变更）  
责任角色：R01 产品、R03 架构、R04 后端、R06 模型算法、R09 测试、R10 运维

## 1. 本轮目标

一期模型发布后，AICM 已产生的模型不做外部回滚。模型出现问题时，由管理人员关闭 LabelU 本平台的下载开关；本平台仍保留发布目录、AICM `model_set_id`、本地模型包和第三方回流别名，便于问题图片按模型编号继续对齐。

本轮只补充验收契约，不增加新的模型实体、不增加项目维度，也不改变标注人员可以发布模型的权限。

## 2. 已核对的业务链

1. 发布成功时，`public_model_id` 与 AICM `model_set_id` 使用同一个字符串/整数编号。
2. 本平台目录下载开关由管理人员控制，并使用 `expected_download_enabled` 做并发冲突检测；旧页面值不能覆盖新值。
3. 下载开关关闭后，已登录的模型中心下载和匿名公开下载均失败；请求不会再向 AICM 拉取模型包。
4. 第三方来源别名只作为查找入口，解析结果仍返回同一 `model_id` 和 `aicm_model_set_id`，支持专家回流样本按模型编号创建任务。
5. 外部 AICM 已发布文件不回滚；`hidden/revoked` 仅是目录状态，不能代替“禁止本平台下载”。

## 3. 本轮交付

- 接口回归：管理员关闭下载后，管理下载接口返回 `409`，公开详情/下载接口不再暴露模型。
- 编号回归：通过第三方来源别名请求下载地址时，响应保持 AICM 编号和本平台编号一致。
- 继续复用现有本地长期保留包、别名解析和乐观锁实现；未引入新表或新的发布状态机。
