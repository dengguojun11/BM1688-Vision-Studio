# RUN-0346 训练流程去掉数据集分类入口（2026-09-21，本地）

## 背景

一期日常治理只保留“标签库”和“数据集管理”。生产接口和历史记录中的 `dataset_category_id` 仍需保留用于兼容，但不能继续出现在新建训练、候选筛选和确认页面，否则用户会误以为还要同时维护“数据集”和“数据集分类”。

## 处理结论

- 训练候选只按“数据集 + 标签”筛选；按任务训练可选数据集和任务标签，按标签训练可选数据集、目标标签和来源任务。
- 训练页面不再请求、展示或提交数据集分类；不再在候选摘要和确认页显示分类名称。
- `dataset_category_id`、`dataset_category_name` 等后端历史字段不删除、不回写，只允许历史任务、旧训练作业、第三方回流和模型血缘对账使用。
- 训练时仍由后端根据数据集标签契约生成或复用冻结数据集版本，用户不需要维护清单和校验码。

  - 数据集选项只展示数据集名称、标签契约和冻结快照状态。
