## 1. 审计结论

标注审核页面属于一期数据回流/审核入口，不能要求用户先选择项目。当前工作树中的 `annotationReview.tsx` 已满足这一规则：

- 标注审核列表调用 `/v1/annotation-reviews` 时只发送分页和状态条件，不发送 `project_id`；
- AI 预测审核列表调用 `/v1/prediction-sets` 时只发送分页和状态条件，不发送 `project_id`；
- 页面不再导入 `usePlatformProject`，不显示“请先选择可访问项目”；
- “处理审核”“批量驳回”“预测投影”均使用现有居中 `Modal` 或页面按钮，不使用抽屉；
- 页面可见文案为中文，历史兼容接口 `project-legacy` 只作为内部投影动作名称，不作为用户菜单或项目选择入口。

规则中心、旧设备发布页仍保留历史项目参数兼容代码，但不在一期主导航中；本轮不扩大改动范围，避免破坏历史只读/兼容链。
