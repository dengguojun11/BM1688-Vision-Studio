# RUN-0231 工作台全局文案与无项目入口回归

## 1. 目标

一期不引入项目/业务空间维度。工作台由 `useWallboard()` 在当前账号授权范围内汇总任务、训练、编译、真机验证、发布和告警；它没有选择项目的前置条件，因此页面不能显示“当前项目”或“项目运行摘要”。历史接口的 `project_id` 兼容参数不在本轮删除。
