## 3. 菜单与按钮闭环

- **工作台**：只展示当前账号可见的任务、训练、模型和异常摘要，不创建新的业务对象。
- **任务与标注**：新建任务、上传/导入图片、自动预标注、人工确认、冻结数据集、新建训练；标注人员和管理人员均可使用。
- **训练中心**：创建训练作业、选择基础 YOLO11 权重或同标签历史 PT、选择全量标签或任务内单标签、查看指标、取消/重试；作业只能引用不可变 `DatasetVersion`。
- **模型中心**：模型版本、边端编译、真机验证、发布记录、下载目录；发布使用 AICM `model_set_id`，本平台保留同一编号的下载包。

## 5. 并发和失败关闭结论

- Web 请求只负责校验和入队；独立 Worker 领取任务并使用队列租约、执行租约和 fencing token，旧 Worker 不能覆盖新代次。
- 同一 BM1688 设备按设备编号单槽执行，避免两个任务同时加载模型；真实容量仍需实测。
- S3 包、AICM 发布和预标注使用稳定幂等键；重复回调和重试不重复创建任务、样本或发布记录。
- 缺少真实模型、固定评估集、工具链、设备、凭据或外部接口证据时，相关 Worker 默认关闭并失败关闭。
- SSH 密码清空只保留设备记录，不自动切换到板端通道；`auto_run_ready=false`，重新填写凭据后才可恢复。
