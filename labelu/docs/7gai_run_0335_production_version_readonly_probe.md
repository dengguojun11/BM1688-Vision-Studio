# RUN-0335 生产版本只读探针与本地放行边界（2026-09-21）

## 1. 目的

在不提交、不部署、不写入业务数据的前提下，核对生产入口是否已经具备一期方案要求的 JSON 健康、就绪和版本探针，为生产版本对齐工作包提供可复核证据。

## 2. 检查范围

生产入口：`http://113.141.72.175:10000`

只读请求：

| 地址 | 结果 | 说明 |
|---|---:|---|
| `/` | `200 text/html` | 返回旧版前端首页，不是 JSON 探针 |
| `/api/v1/health` | `404` | 当前生产没有健康接口 |
| `/api/v1/ready` | `404` | 当前生产没有就绪接口 |
| `/api/v1/version` | `404` | 当前生产没有版本接口 |
| `/openapi.json` | `200 application/json` | FastAPI 文档入口仍可访问 |

## 3. 结论

- 生产版本与本地一期方案不对齐，不能用本地测试结果替代生产验收。
- 生产健康、就绪、版本接口缺失，后续预生产部署必须先补齐反向代理和接口探针，再执行统一脚本复验。
- 本轮未调用登录接口、未创建任务、未上传文件、未修改标签、未触发训练或发布。
- 本轮未提交、未推送、未部署；生产环境没有写入操作。
