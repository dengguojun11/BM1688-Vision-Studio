## 失败分类

1. **已退休入口的旧成功断言**：旧 `projects` 创建、`edge-device-jobs` 创建/领取、规则中心和设备签名测试仍要求成功。当前一期契约要求这些旧控制面在写入前返回 `403`，不能恢复旧写链。
2. **去项目化后的旧模型构造**：第三方回调测试仍向已去项目化的 `StrategyTaskIntegration` 构造器传入 `project_id`。历史列/查询兼容需要保留，但新 ORM 写模型不再接受该字段。
3. **自动训练计划人工写入口**：本地评估和持久化测试直接调用已关闭的人工计划写接口，触发 `ensure_auto_training_plan_writes_open()`。一期自动进化由 S3 回流、聚合、任务复用和 Worker 触发，不恢复人工计划写链。
4. **项目前置数据治理测试**：数据集版本校验接口测试仍先创建项目，和一期无项目主链冲突，需要改为任务/数据集全局作用域夹具。

这些失败没有发现一期主链的新运行时异常；一期专项和联合回归见 RUN-0203、RUN-0204、RUN-0205、RUN-0207。

## 后续处理

- 在迁移测试契约前，不把全量 `pytest labelu/tests/internal` 的非零结果误报为生产可验收；当前使用已确认的主链专项集合作为本地 L1 验收证据。
