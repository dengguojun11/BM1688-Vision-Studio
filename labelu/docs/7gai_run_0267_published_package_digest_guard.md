# RUN-0267 发布模型包摘要一致性门禁（2026-09-20）

## 发现

模型中心发布目录的下载流程已有路径归属和 ZIP 格式检查，但磁盘上的长期保留包可能被人工或异常进程替换。此前下载流程没有在登记摘要存在时再次比对 `package_sha256` 和文件大小，不能证明下载的是发布时登记的不可变制品。

## 修改

- 新增下载前完整性校验：登记了 `package_size_bytes` 时校验大小；登记了 `package_sha256` 时重新计算并校验 SHA256。
- 不一致统一返回 `409`，不提供被替换的文件下载。
- 历史没有摘要的目录记录保持只读兼容，不伪造摘要；新发布/缓存流程继续写入摘要。
- 未改变“发布后不回滚，只能停止本平台后续下载”的产品语义。

新增场景：登记 SHA256 与磁盘 ZIP 不一致时拒绝下载；已有本地包、远端缓存、别名下载和禁用下载开关回归通过。
