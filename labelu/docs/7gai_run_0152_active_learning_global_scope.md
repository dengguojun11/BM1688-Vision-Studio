# RUN-0152 主动学习聚类与批次去项目化（本地 L1）

日期：2026-09-19（Asia/Shanghai）

## 1. 本轮目标

把第三方 S3/边端问题样本进入主动学习后的“聚类”和“生成批次”从项目维度迁移到统一的进化范围。历史数据仍保留 `project_id`，新数据使用 `scope_key=global`；不新增项目/业务空间菜单，也不通过默认项目编号绕过权限。

## 2. 已实现

- `FeedbackCluster` 使用 `(scope_key, cluster_key)` 唯一约束；记录创建人、来源模型和来源包。
- `ActiveLearningBatch` 使用 `(scope_key, batch_key)` 唯一约束；记录来源模型和来源包。
- 聚类键按“难例类型、设备、模型版本、第三方来源包”生成，同一全局队列不会把不同模型或不同来源包混为一组。
- 重建聚类接口和聚类查询接口的 `project_id` 均可省略；省略时进入 `global` 作用域。管理人员可执行全局重建，标注人员按创建人、历史任务/项目权限和模型创建人看到可见聚类。
- 生成批次接口支持无项目请求。自动幂等键包含作用域、模型、来源包和本次难例集合；并发或网络重试返回原批次，不重复占用难例。
- 边端难例审核通过后立即刷新全局聚类，避免“已入队但聚类页面看不到”。
- 历史带项目请求和查询仍按 `project:<id>` 作用域兼容。

## 6. 菜单和按钮验收口径

“进化中心”页面只保留两个工作区，不增加项目选择器：

| 页面区域 | 标注人员 | 管理人员 | 关键按钮及行为 |
|---|---|---|---|
| 难例审核 | 查看本人可见难例；全局回流审核提交由管理人员执行 | 查看全部、接受或排除 | `查看` 打开居中弹窗；`提交审核` 需要在线且排除时必须填写理由；终态只能查看，不能重复提交 |
| 回流编排 | 查看本人可见聚类和批次，不显示管理按钮 | 重建聚类、生成批次、接受批次、校验并冻结 | `重建聚类` 和 `生成训练批次` 仅管理人员执行；相同批次输入并发重复提交返回同一批次；`接受批次并创建工作流` 后自动落数据集版本和工作流 |
| 数据集版本与冻结 | 查看状态 | 校验并冻结 | 冻结前不进入训练；失败时保留待复核状态，不产生训练副作用 |
| 关联重训工作流 | 查看进度与错误 | 查看进度与错误 | 仅展示自动创建的专家回流工作流，不在此重复创建任务 |

所有详情均使用居中弹窗，不使用抽屉；按钮请求不得携带 `project_id`。后端以 `scope_key=global` 作为新数据的幂等和查询边界。
