## 1. 复核目的

确认“代码迁移闭包检查”和“真正允许连接 MySQL/生产迁移的证据闸门”不是同一个结论，避免本地通过被误读为生产可以升级。

## 2. 实际执行结果

### 2.1 本地代码安全闭包

```text
python -m labelu.scripts.release_gate
migration_heads=z9f3a4b5c6d7
security_valid=True
backup_restore_ok=True

退出码：0
```

该命令只说明当前 Alembic head、安全配置和本地代码级闭包满足要求，不代表已经连接或升级生产 MySQL。

### 2.2 正式迁移发布闸门

```text
python labelu/scripts/migration_release_gate.py
退出码：1
```

失败关闭项：

- 未提供同版本 MySQL 沙箱 URL；
- 未提供备份恢复证据文件；
- 未提供锁等待证据文件；
- 未提供 `2/10/20/50` 并发矩阵证据文件。

唯一 head、ORM 字段/索引闭包和候选迁移正式来源检查通过；缺少真实环境证据时不会连接数据库。

## 3. 放行含义

当前状态是“代码结构可进入预生产准备，但不能执行生产迁移”。必须先在同版本 MySQL 沙箱完成：备份摘要、独立恢复目标、首次/重复升级、锁等待、双 Worker 领取互斥、旧 token 拒绝和 `2/10/20/50` 并发矩阵，再把证据文件传给正式闸门。

## 4. 生产边界

本轮未连接任何生产数据库，未执行 DDL、备份、恢复、Worker 启停或部署，未提交、未推送、未部署。生产只读路由问题仍由 `RUN-0241` 记录。
