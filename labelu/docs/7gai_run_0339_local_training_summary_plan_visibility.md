# RUN-0339 本地训练摘要与自动计划页面可见性修正

## 结论

本轮只修本地实现，线上环境仅作只读参考。此前本地验收数据库已经存在自动训练计划，但训练中心页面显示“暂无数据”，原因不是数据丢失，而是统一接口 `GET /v1/training/summary` 将自动训练摘要硬编码为 `plan_count=0`，且没有返回 `plans` 数组。

同时发现，训练页面在权限接口尚未返回时立即把 `view=auto-plan` 判定为无权限并清除地址参数，导致管理员从直达链接进入时被错误切回训练作业。

## 本轮改动

### 后端

- 训练摘要接口复用 `auto_training_plan.list_plans` 的现有可见性和计划详情组装逻辑。
- 返回 `plan_count`、`active_plan_count`、`plans`，不引入项目参数。
- 活跃计划状态沿用自动训练状态机：运行中、等待数据、等待审核、等待覆盖度、轮次运行中。
- 自动训练写入口仍保持关闭；本轮只读查询不改变训练调度和生产开关。

### 前端

- 权限查询完成前不清除 `view=auto-plan`，避免管理员首屏竞态被错误跳转。
- 权限确认后仍保持标注人员不可见历史自动训练计划的原有规则。
- 增加权限加载期间保留计划视图的回归测试。
