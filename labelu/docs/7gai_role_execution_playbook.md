# 7GAI 按角色开发执行手册

## 1. 使用边界

本手册是《7GAI 进化平台菜单级产品与业务闭环方案》的开发执行入口。系统只保留两类登录用户：

- **标注人员**：可以创建任务、上传图片、选择标签、发起预标注、人工确认、冻结数据、创建训练、查看模型并发布模型；不能修改平台安全策略、设备注册、第三方 S3 连接和质量门禁。
- **管理人员**：拥有标注人员全部能力，并负责平台规则、设备、第三方连接、异常回流、质量门禁和下载禁用。系统自动处理正常回流，管理人员只处理异常和抽查。

不新增项目、业务空间、设备发布、OTA 或模型回滚菜单。已发布模型出现问题时，只把平台和外部下载状态改为“禁止下载”，再发布替代模型；不尝试撤回已经下载到其他平台的文件。

## 2. 固定菜单与按钮验收

一期一级菜单固定为：工作台、任务与标注、训练中心、模型中心、进化中心、系统管理。历史“数据回流”仅指进化中心，“平台设置”仅指系统管理，不单独增加菜单。

### 2.0 工作台

工作台只展示当前账号可见的任务、训练、模型和异常摘要，并提供进入对应页面的快捷按钮；不在工作台创建新的任务、数据集、模型或回流批次。标注人员按本人任务/协作权限查看，管理人员可查看全局摘要。验收必须核对摘要数量与目标列表一致、无项目选择、无越权对象。

### 2.1 任务与标注

| 页面按钮 | 标注人员 | 管理人员 | 通过条件 |
|---|---|---|---|
| 新建任务 | 可用 | 可用 | 任务、图片类型、标注工具和预置标签契约一次提交；不要求项目编号 |
| 上传图片/导入 S3 | 可用 | 可用 | 文件安全扫描、重复指纹和来源记录完成；失败文件不进入标注队列 |
| 开始预标注 | 可用 | 可用 | 系统按图片类型、工具和标签契约自动选择兼容模型；任务级按钮只创建一次幂等作业 |
| 人工确认/批量确认 | 可用 | 可用 | 预标注结果与人工修改分开保存；未确认样本不能冻结 |
| 冻结数据集 | 可用 | 可用 | 自动生成不可变数据版本、标签快照、训练/验证/测试划分和清单摘要 |
| 新建训练 | 可用 | 可用 | 可选基础模型或同标签历史 PT；可选全量标签或当前任务的单个标签；作业绑定冻结版本 |

一期只支持目标检测矩形框。车牌定位只标车牌外接矩形，不标车牌号，不使用多边形；不同框类型不得在同一检测训练契约中混用。

### 2.2 训练中心

| 页面按钮 | 标注人员 | 管理人员 | 通过条件 |
|---|---|---|---|
| 创建训练作业 | 可用 | 可用 | 训练作业引用唯一 `DatasetVersion`；不接受用户手工 manifest 覆盖 |
| 选择权重 | 可用 | 可用 | 基础 YOLO11 权重与同标签历史 PT 分开显示；类别契约不一致时禁止提交 |
| 查看日志/指标 | 可用 | 可用 | 日志、指标、阶段文件均带作业代次和执行租约；旧 Worker 不能覆盖新状态 |
| 取消/重试 | 可用 | 可用 | 只允许当前执行者或已过期租约重试；重试生成新执行代次，不复用旧制品 |

训练顺序固定为 **PT 训练 → 导出静态 ONNX → 服务器 TPU-MLIR 编译 → FP32/FP16/INT8 三个 BModel → BM1688 真机验证**。BM1688 只加载和推理，不在板端编译。

### 2.3 模型中心

模型中心只保存一条模型版本血缘：PT、ONNX、FP32/FP16/INT8 BModel、固定评估集、BM1688 证据和 AICM `model_set_id`。页面至少提供以下子菜单或页签：

- **模型版本**：查看训练来源、数据版本、类别契约、清单签名和制品完整性。
- **边端编译**：提交导出/重编译任务，查看 TPU-MLIR 版本、Profile 摘要和三精度结果。
- **真机验证**：选择已注册 BM1688 设备，查看三精度加载、有效推理数、精度、P95 和短稳证据。
- **发布记录**：查看 AICM 发布状态、AICM `model_set_id`、本平台保留包和发布人。标注人员和管理人员都可以发布，发布前必须通过系统门禁。
- **下载目录**：按 AICM `model_set_id` 提供本平台下载；管理人员可以“禁止后续下载”，不能回滚外部平台已下载文件。

模型制品清单必须由服务端签名。服务器使用私钥签名，Board Agent/SSH runner 只持有公钥并在加载前验签；密钥不下发 BM1688。

### 2.4 进化中心

进化中心不要求人工逐包建任务。系统自动从第三方 S3/MinIO 接收问题图片包，执行下载、校验、内容指纹去重、按 AICM `model_set_id` 聚合、预标注、创建或复用任务、生成数据版本并触发评估/训练。管理人员只处理：模型 ID 冲突、标签契约异常、低置信样本、重复候选确认和抽查失败。

| 页面按钮 | 标注人员 | 管理人员 | 通过条件 |
|---|---|---|---|
| 查看回流批次 | 只读 | 可用 | 能看到来源包、模型 ID、去重数量和当前自动处理状态 |
| 审核异常 | 不可用 | 可用 | 处理冲突/异常后可重放单包，不重复创建任务 |
| 查看难例/重新标注 | 可用 | 可用 | 按任务权限进入标注；确认结果回写原来源和模型 ID |
| 手动触发重试 | 不可用 | 可用 | 仅重试失败阶段，保留原包幂等键和执行证据 |

### 2.5 系统管理

系统管理只由管理人员使用，所有编辑使用居中弹窗：

| 页面按钮 | 标注人员 | 管理人员 | 通过条件 |
|---|---|---|---|
| 编辑标签契约 | 不可用 | 可用 | 新版本保留历史引用；影响任务和训练的范围在确认弹窗显示 |
| 编辑预标注兼容关系 | 不可用 | 可用 | 图片类型、矩形框工具和标签顺序不兼容时禁止启用 |
| 编辑质量门禁/BM1688 Profile | 不可用 | 可用 | 规则版本化；缺固定评估集、三精度或真机证据时失败关闭 |
| 管理设备、AICM、S3 连接 | 不可用 | 可用 | 密钥不显示；连接测试、超时、重试和审计记录齐全 |
| 开关运行任务 | 不可用 | 可用 | 训练/编译/边端/回流 Worker 默认关闭；未达到生产证据等级不得打开 |
| 禁止后续下载 | 不可用 | 可用 | 仅影响本平台后续下载；不宣称召回外部平台已下载文件 |

### 2.6 系统管理原则补充（历史“平台设置”兼容说明）

平台设置只放规则和连接，不承载业务数据创建：标签契约、预标注模型兼容关系、质量门禁、BM1688 Profile、设备注册、AICM 环境、第三方 S3 连接、下载禁用和运行开关。所有编辑均使用居中弹窗；提交前显示影响范围和并发冲突提示。

## 3. 角色开发边界

| 角色 | 主责 | 每轮必须交付 |
|---|---|---|
| R01 产品 | 菜单、按钮、权限和业务状态 | 业务规则、异常边界、验收场景和对应 RUN 文档 |
| R02 数据契约/体验 | 标签、数据版本、清单和可读文案 | 请求/响应字段、兼容策略、中文状态和交互验收 |
| R03 架构/迁移 | 血缘、租约、fencing、迁移和并发设计 | 代码路径、表/索引影响、并发窗口和放行门槛 |
| R04 后端 | 路由、服务、Worker 和事务 | API、权限、幂等、失败关闭和专项测试 |
| R05 外部平台 | AICM、S3、第三方回流 | 外部 ID 对账、重试、限流、签名和异常回流证据 |
| R06 模型算法 | YOLO/车牌训练、评估和阈值 | 数据契约、PT/ONNX/BModel 关系、固定评估集和质量判定 |
| R07 BM1688 边端 | TPU-MLIR、Board Agent、真机推理 | 公钥验签、设备加载、P95、短稳、断网和资源释放证据 |
| R08 前端/UI | 菜单、按钮、中文弹窗和页面状态 | 桌面/窄屏交互、权限隐藏、重复点击和真实 API 联调 |
| R09 测试 | 单测、接口、并发、浏览器和放行证据 | 测试命令、通过计数、失败原因、证据文件和回归结论 |
| R10 运维/生产 | MySQL、systemd、Nginx、密钥和发布 | 备份、迁移、探针、容量、重启接管、生产只读/写入证据 |

## 4. 每轮开发记录模板

每个工作包必须创建独立文件 `labelu/docs/7gai_run_<编号>_<主题>.md`，并同步 `7gai_role_delivery_plan.md` 与 `7gai_delivery_ledger.md`。文档必须包含：

1. 目标、涉及菜单/按钮、主责角色和协作角色。
2. 修改的代码、页面、接口、数据库和配置文件。
3. 权限、幂等、并发、租约/fencing 和失败关闭行为。
4. 测试命令、通过/失败数量和关键断言。
5. 本地、预生产、生产证据；没有真实证据必须明确写“未完成”。
6. 风险、下一依赖、是否允许提交/部署，以及 L0-L4 验收等级。

## 5. 验收等级

- **L0**：完成分析和代码路径核对，无代码变更。
- **L1**：本地代码与专项测试通过；不代表真实外部系统、MySQL、TPU-MLIR 或 BM1688 通过。
- **L2**：同版本 MySQL/预生产、并发、迁移和外部接口证据通过。
- **L3**：真实 GPU、TPU-MLIR、BM1688、S3/AICM、systemd 和浏览器联调通过。
- **L4**：生产小流量、监控、备份恢复和问题处置演练通过。

任何一项 P0 没有达到对应等级，都必须保持相关 Worker 或自动训练开关关闭；不得用 HTTP 200、模拟器、单条数据库记录或本地测试替代生产证据。
