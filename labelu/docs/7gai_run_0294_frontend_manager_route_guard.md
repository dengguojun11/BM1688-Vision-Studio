# RUN-0294 前端系统管理路由守卫与两类角色入口闭环

## 1. 目标与菜单按钮

- 一级菜单：系统管理。
- 受保护入口：`/admin`，以及历史规则、异常流程、数据集兼容入口跳转到 `/admin` 的路径。
- 两类用户：标注人员、管理人员。
- 标注人员仍可创建任务、上传图片、预标注、人工确认、训练和发布模型；系统管理只对管理人员开放。
- 主责：R01 产品、R08 前端/UI、R09 测试；协作 R04 后端、R10 运维。

## 2. 本轮交付

### 前端路由守卫

新增 `RequireManager`：

- 使用已有 `/v1/users/me` 和 `is_task_superuser` 判定管理人员，兼容旧版内置管理员账号解析。
- 当前用户请求加载中只显示中文权限校验状态。
- 标注人员在管理页路由级重定向到工作台，不渲染管理页面内容。
- 当前用户请求失败时失败关闭，显示无权限提示，不允许把网络故障当成管理员。
- 管理人员通过后才渲染系统管理页面。

### 导航与服务端边界

- 平台布局原有逻辑继续隐藏标注人员左侧“系统管理”菜单。
- 本轮增加的是直接输入 URL、历史兼容跳转和刷新场景的路由守卫。
- 后端管理接口的 401/403 校验不移除；前端只负责体验和提前阻断，不能替代服务端权限。

## 4. 权限、并发与失败关闭

- 权限判定复用 React Query 当前用户缓存，避免每次页面切换重复请求。
- 守卫只依赖用户身份查询，不启动训练、回流或设备任务，因而不会增加后台并发压力。
- 查询失败、身份字段缺失或非管理人员均按无权限处理。
- 标注人员可继续访问任务、训练、模型中心和发布按钮；本轮不收紧这些已确认权限。
