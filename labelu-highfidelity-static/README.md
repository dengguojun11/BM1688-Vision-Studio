# LabelU High-Fidelity Static Prototype

This folder contains two deliverables:

- `analysis.md`: competitor mapping, current LabelU capability mapping, optimization judgment, and suggested additions
- `index.html`: a clickable high-fidelity static prototype for a stronger LabelU product direction

Open `index.html` directly in a browser, or serve this folder locally:

```powershell
cd D:\PycharmProjects\labelU\labelu-highfidelity-static
python -m http.server 9011
```

Then visit:

`http://127.0.0.1:9011`

The prototype is intentionally static, but it supports realistic click-through behavior across:

- program overview
- training workspace
- quality policy studio
- edge validation center
- publish gate
- competitor delta mapping
