流程状态

统一理解：编译配置 → 模型编译 → 边端验证 → INT8 评估 → 发布判定
1. 编译配置 设置自动编译、量化模式、目标平台、边端 SSH 和默认校准方式。
2. 模型编译 训练产物导出 ONNX，再生成 fp32 / fp16 / int8 三类 bmodel。
3. 边端验证 把模型和测试图下发到边端，确认 bmodel 在目标设备上可以真正运行。
4. INT8 评估 比较 PT、ONNX、INT8 的 test 集结果，判断精度是否在阈值内。
5. 发布判定 给出“可进入发布评估 / 待补充验证 / 不建议发布”的清晰结论。
