实现方案
A

独立扩展页 + 临时推理接口

新增 `/yolo-model-validate` 页面和一个单图上传推理 API，模型库“更多”新开窗口跳转过去。

B

当前页弹层

不新开页面，直接在模型库页弹出大弹层做左右对比，改动较小但不符合当前目标。

C

复用预标注页能力

把已有 YOLO 推理能力抽成通用入口，但会把“临时验证”和“任务预标注”耦合，首版偏重。

推荐边界

首版做

  • 只支持单张图片上传
  • 左原图右结果图并排对比
  • 调用该训练作业 best.pt 即时推理
  • 返回结果图和检测明细

首版不做

  • 不保存验证历史
  • 不批量上传
  • 不和任务样本或预标注打通
